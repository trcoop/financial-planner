# Visual regression tests

Playwright screenshot diffing, self-hosted (no external SaaS — see the "CSS/visual
regression testing" entry in the team's Deferred/Future Considerations doc, resolved by
FIN-127). Two suites:

- `stories.spec.ts` — one screenshot per Ladle story (`.ladle-build/meta.json`, generated by
  the `stories` project's `webServer` command), each in Ladle's chromeless preview mode.
- `pages.spec.ts` — full-page screenshots of the app's two top-level sections (Plan,
  Calculators), against a production build served by `vite preview`.

## Running locally

```
npm run test:visual          # compare against committed baselines
npm run test:visual:update   # regenerate baselines
```

**Baselines are OS-specific** (Playwright suffixes snapshot filenames with the platform, and
font rendering differs by OS) — CI runs on `ubuntu-latest`, so baselines must be generated on
Linux. If you're on macOS/Windows, don't run `test:visual:update` locally: use the
"Update visual baselines" GitHub Actions workflow (`workflow_dispatch`) instead, then download
its `visual-baselines` artifact and commit the PNGs it contains.

## CI

The `visual` job in `.github/workflows/ci.yml` runs `test:visual` (compare mode) on every PR
and push to `main`, and is a required status check on `main`.
